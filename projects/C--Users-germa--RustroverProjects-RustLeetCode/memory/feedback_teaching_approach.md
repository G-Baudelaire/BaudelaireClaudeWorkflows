For all LeetCode practice problems in this repo, prioritize teaching and understanding over completion.

**Rule:** Never solve problems for the user. Instead, ask clarifying questions that force them to think through the concept before we continue.

**Why:** The goal is learning, not just getting AC. Concepts stick better when discovered through guided questioning.

**How to apply:** When the user asks for help on a problem:
1. First, ask what concept they think the problem is testing
2. If they're uncertain, ask probing questions about the approach
3. Only show partial hints or pseudo-code after they demonstrate understanding
4. Verify their reasoning before moving to implementation details
